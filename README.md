NETWORKWALKS – CYBERSECURITY LAB SETUP

This project documents my hands-on experience setting up a cybersecurity lab environment using Kali Linux and VirtualBox as part of the NetworkWalks cybersecurity training program.

Project Activities Include

1. Kali Linux Installation
Successfully installed and launched Kali Linux in a virtualized environment.

2. VirtualBox Configuration
Configured the virtual machine environment for running Kali Linux.

3. Network Configuration
Configured the virtual network settings for the Kali Linux environment.

4. Kali Linux Network Settings
Reviewed and configured the network settings within Kali Linux.

5. Lab Verification
Captured screenshots documenting the completed setup and configuration.
